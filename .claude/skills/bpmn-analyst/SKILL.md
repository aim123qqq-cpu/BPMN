# BPMN-аналитик (точка входа для Claude Code)

Методика общая для всех нейросетей и лежит в корне репозитория. Прочитай
`skills/bpmn-analyst/SKILL.md` (путь от корня репозитория bpmn-agent) и работай строго по нему; справочники —
в `skills/bpmn-analyst/references/`.

Особенности Claude Code:
- вводные из шага 0 уточняй через AskUserQuestion (один вызов, до 4 вопросов, с рекомендуемыми вариантами);
- PNG из `render` смотри инструментом Read — визуальная самопроверка обязательна.
